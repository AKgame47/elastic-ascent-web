# Elastic Ascent - playable build

Public runtime files only. The editable Godot project and original source archive are kept separately in a private repository.

Pull down and release to launch upward. Shatter obstacles while glowing.

This browser build necessarily downloads compiled game data to the player. It does not include the editable source project, raw GDScript files or a source ZIP.
